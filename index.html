Proyecto Académico: Mini-Atlas Multimedia de Signos Vitales

Asignatura: Informática Aplicada a la Medicina (3° Semestre)

Alumno: Alina Yamileth Soria Flores

1. Descripción General del Proyecto

Este proyecto consiste en el desarrollo de una interfaz web interactiva diseñada con Visual Studio Code y estructurada mediante un archivo principal index.html. Su propósito central es servir como una herramienta de apoyo didáctico y de consulta rápida para estudiantes de ciencias de la salud, enfocándose en la correcta toma e interpretación de los signos vitales básicos, tales como la presión arterial, la frecuencia cardíaca y la temperatura corporal.

2. Justificación y Utilidad Clínica

En las etapas formativas del tercer semestre de la carrera de medicina, la adquisición de habilidades prácticas en semiología y exploración física es fundamental. Este sitio web recopila material visual y audiovisual generado para estandarizar los pasos metodológicos de la exploración clínica, evitando errores comunes durante la medición de parámetros hemodinámicos y mejorando el aprendizaje práctico.

3. Implementación Multimedia (Imágenes, Vídeo y Audios)

Para enriquecer la experiencia educativa, el sitio web integra de forma directa elementos multimedia esenciales:

  • Soporte Visual (Imágenes): Se incorporaron fotografías clínicas detalladas que muestran la colocación anatómica correcta y los instrumentos de medición clínica.
  • Soporte Audiovisual y Sonoro: Se adjuntó la presentación en vídeo y los audios de referencia clínica (latidos cardíacos, frecuencia respiratoria y ambiente clínico).

4. Conclusión

El desarrollo de este proyecto no solo fortalece las competencias técnicas en el uso de editores de código como Visual Studio Code y lenguajes de marcado web, sino que también vincula la informática con la práctica médica cotidiana, facilitando la difusión moderna, accesible y visual de los conocimientos clínicos adquiridos durante el semestre.
